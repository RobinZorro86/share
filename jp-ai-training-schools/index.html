六条结论

给关西中小企业 AI 咨询业务的对标要点，先看这里，再看各家明细。

1

规模梯队清晰，平台型靠 ID 定额碾压价格。Udemy Japan（国内 200 万人+）、Progate（全球 370 万用户）、Schoo（会员约 135–144 万）、Insource（年受讲 79.2 万人、东证 Prime）以月 1,650–5,990 円/人的定额制占据规模端，中小机构无法正面拼 e-learning 单价。

2

AI 专精梯队各有王牌。SHIFT AI 付费会员 40,000+、B2C 社区最强；キカガク受讲生 20 万人、导入 1,000 社+；AVILEN 约 1,000 社、东证 Growth 上市；Aidemy 有 400 法人+、2025-11 被 Accenture 收购、个人向 Premium 已于 2026-06-30 结束；DMM 生成AI CAMP 于 2026-03 改版为月额学び放題。

3

Agent 课程已成标配。24 家中 18 家有明确 AIエージェント课程（另有部分/轻量）。主导工具是无代码的 Dify（AVILEN、キカガク、スキルアップAI、トレノケート、CodeCamp、DMM、インターネット・アカデミー都在用）；第二波是 Claude Code / Codex（SHIFT AI、バイテックGEEK、AI Agent Camp、DMM、Progate beta）；微软系企业走 Copilot Studio / Copilot Agent（Insource、AVILEN、Udemy BOC）。

4

Agent 课价格带分四档。入门 e-learning / 半日 33,000–38,500 円 → 实战ハンズオン 100,000–120,000 円（キカガク Dify 0.5 日 100,000 円税抜、スキルアップAI 120,000 円税込/约 5h）→ 开发养成 165,000–385,000 円 → 套餐/伴走 300,000 円税抜/名（SHIFT AI for Biz）起。

5

没有 Agent 课的是可争夺人群。Winスクール只有 ChatGPT/Copilot 基础，无 agent 構築课；TechAcademy 的 LLMアプリ開発新規受付一時停止中；スタディサプリ是 K-12、非成人研修竞品。这三家的用户存在迁移空间。

6

免费引流与补助金话术是行业标配。SHIFT AI 每周约 2 次免费 Agent 实演セミナー、DMM 60 分免费说明、Aidemy Business 免费トライアル、Schoo 每日免费生放送、Progate 免费层、Udemy Business 14 日トライアル；人材開発支援助成金 / 教育訓練給付金（最大 80%）、リスキリング補助金（最大 70%）与「実質 XX 円」话术几乎人人都在用。

对关西中小企业的对标启示

基于上表事实的归纳，供内部定价与课程设计参考。

卡价格空档

38,500 円（AVILEN e-learning）与 100,000–120,000 円（キカガク / スキルアップAI ハンズオン）之间、以及「Dify 构建后无伴走」，是中小企业最痛的两点。关西本地对面/混合 + 以自社数据为课题的ハンズオン若定在 55,000–88,000 円/名，正好卡位（参照：インターネット・アカデミー 78,408 円、トレノケート 77,000 円）。

不拼 ID 定额，拼成果物

Schoo 1,650 円/ID、Progate 1,990 円/人、Udemy 年 18,100 円〜的定额价格无法跟。差异化应放在「构建出可用的成果物 + 课后定着」，而不是课时数量。

工具选型跟随主流

Dify 是必备第一课，Claude Code 是 2026 年的第二课；微软系企业（Copilot Studio / Copilot Agent）单独成班，对应 Insource 的打法。

线下教 Agent 在大阪常设层面是空档

线下教 Dify / Claude Code 做 Agent 的供给，在大阪常设层面稀缺，是空档。现有大阪线下多为基础通学（Win、ヒューマン、テックジム）或不定期会場公開講座（AI研究所、Generative Agents 的大阪回、Insource 来場型、スキルアップAI 大阪対面回）；常设教室里持续开 Dify 構築 / Claude Code 实战、且能用客户自社课题做成果物的供给几乎没有。这正是关西本地对面小班可以卡位的地方。
