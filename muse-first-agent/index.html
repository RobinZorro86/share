普通人的第一个 Agent

普通人为什么最该用的 Agent，就是 Muse。

先说清一个词：Agent，就是「会自己动手干活的 AI」。Muse 是 Meta（做 Facebook、Instagram 的那家公司）出的一个免费个人助理：你像给朋友发消息一样交代一件事，它自己去查、去做，做完把成品交给你。不用懂技术，打开就能用。

先给结论

三个核心论点

01

免费版就是完整版，不是阉割版

免费版和付费版功能一样，区别只有两点：每周能用的量更大、大脑更强一点。不存在「正干着活，弹出一个付费墙」这种事。

02

它像个助理，不像个软件

用法就是发消息交代事情，跟交代一个真人助理一样。它自己安排步骤、自己动手，拿不准的回来问你，做完向你汇报。不用学提问技巧，不用自己配置任何东西。

03

用量大方，不用算着花

很多 AI 按次、按小时算账，用的时候心里总在打鼓。Muse 每周给你一大包用量，还配了个像手机电量一样的百分比显示。实测下来，普通人一周连零头都用不完。

普通人能让它干什么

不是陪你聊天，是替你把事办了

日常生活

  • 定时替你盯事——到点自己去看，有情况才来找你
  • 管邮件和日历——帮你找邮件、分轻重、看你哪天有空、约时间
  • 规划旅行——行程随时更新，证件这类有期限的事单独盯紧
  • 买东西比价——几家店连运费一起算，告诉你买哪家划算
  • 整理健康记录——睡眠、运动的变化趋势（看病还得找医生）

轻办公

  • 读完资料写成稿——几十份文件读完，给你一份能直接发出去的成品
  • 每周自动出周报——定好一次，以后每周自己查、自己排版、自己发给你
  • 帮你写邮件——照着原来的邮件往来起草，你点头了才发
  • 整理会议记录——会上定了什么、谁负责什么，一次理清
  • 做调研出报告——查原文、标出处，查不到就老实说查不到

家庭与学习

  • 陪孩子学习——按孩子的成绩和兴趣出练习题
  • 记成绩看趋势——每次成绩记进表里，看哪科在进步、哪科在掉
  • 做复习计划——先摸底，再把任务排到每一周
  • 盯学校通知——补习班、学校的截止日期，一个不落

创作

  • 做网页——写好、放到网上、给你链接，你说改它就改（这一页就是它做的）
  • 做图、做视频、配音——生成和修改都行，还能做成播客那样的音频
  • 订制你的资讯早报——按你定的题目定期供稿，旧新闻不发
  • 帮你想点子、盯长远目标——它会主动提议能帮你做的事，进展定期汇报

为什么聊天 AI 干不了这些？四个原因：它进不了你的账号、你关掉页面它就停工、它记不住你、它交不出成品文件。Muse 这四样都有。

上手先做什么

先给它两把钥匙：Google 和 GitHub

所谓「连接器」，说白了就是你给助理配的钥匙：你把邮箱、日历的钥匙给它，它才能进去替你干活；钥匙随时能收回，还能设成「只准看、不准动」。这两把不给，它再聪明也只能陪你聊天，大概只发挥得出三成功力。

第一把 · Google
邮箱、日历、网盘、文档、表格……点一次授权就全接通。前面讲的孩子学习档案、报考档案、每周周报，靠的都是这一把。建议先全设成「只准看」，用一周看它找得准不准，再慢慢放开。
第二把 · GitHub
听着像程序员的东西，其实是给 Muse 的产出安个「家」：它做的网页、文档存放在这里，变成一个固定网址，你能直接发给别人看。不写代码的人，就当它是作品集兼备份盘。
一开始就能用的
查网页、看图片、去社交平台上搜消息——装上 Muse 就自带，先把这些用熟。
用熟了再加的
x-search（专门去 X 上听一手消息）、Scrapling（有些网页普通浏览器打不开、它能打开，比如微信公众号文章）、pi-web-access（让另一个小助手帮忙批量搬资料）。
高手玩的
我家 Hermes 团队的负责人 Luffy 推荐的四样，各补一个短板：anysearch——查财报、专利、论文这类专业资料更准；agent-reach——能看到要登录才能看的小红书、B站真实帖子和评论；Firecrawl——翻论文、法规这类专业资料库（它靠一个叫 MCP 的「万能插头」接进来，能接各种软件）；wigolo——把网页存下来，还能盯着它变没变。这四样要自己动手配置，知道有就行，不用急着装。

自带的搜索解决「找得到」，这四样补的是「找得准、存得下、盯得住」。

我的真实案例 · 孩子学习

这些都不是「问答」，是「托管」

案例一 · 英检準 2 級备考

408个格子的学习档案表
35份真题试卷，全部核对过
4 / 15摸底词汇 15 题只对 4 题，短板一下定位
16周复习计划 + 报名提醒

把孩子以前的 3 张成绩单发给它，当天就建成一张学习档案表。摸底结论一句话：听力底子还在（30 题对 22 题），最大的短板是词汇，不是「英语不行」。然后排了 16 周计划、备好 4 份专项练习，连报名开始的日子都设了提醒。此后每次考完，把成绩发给它，它自己记进表里，看哪科在涨、哪科在跌。

案例二 · 中学受験报考调研

10所候选学校，逐校读官方招生简章原文
1所确认给英语证书加分（清風南海）
3份择校档案和对比报告

四天王寺、清風南海、高槻、開明、大阪桐蔭、同志社香里、神戸女学院、須磨学園、白陵、帝塚山学院泉ヶ丘——考什么、英语证书能不能加分、学费多少，全藏在各校官网的文件里，网上论坛的转述又多又错。逐校读完原文，结论有点反常识：10 所里只有清風南海给英检加分（2 級 +10 分、準 1 級以上 +20 分，还有限定条件）。它还把天王寺和池田两所附属校做了全面对比，结论没变：第一志愿还是天王寺。

案例三 · 浜学園通知每周自动检查

27条通知，一次盘清
4条新通知，第一次跑就抓到
每周日晚自动去看（这就叫「定时任务」）

补习班的通知都锁在家长页面里，不登录就不知道，很容易错过。现在每周日晚，它自己去看一遍，有新通知才用中文发给我；只看女儿所在的上本町校区的，再加上全校统一的规则、费用和截止日。第一次跑就抓到一条「社会科追加报名、10 月 25 日截止」——这种事，错过就没了。

怎么开始

四步，今晚就能开始

01

下载 App，或打开 muse.ai

认准 Meta 出品的 “Muse from Meta”——已经有同名的仿冒 App 了。用 Facebook / Instagram 账号，或者邮箱、手机号注册都行。

02

给她起个名字，配个头像

先把她变成「你的」：给她起个名字、做一个头像，再定下她的性格和做事的风格——性格写进一个小设定里（小字一点：这个设定叫 SOUL，是说话温和还是干练、主动还是稳重），做事的规矩和风格写进另一个小设定里（叫 AGENTS）。设定完，她就不再是「一个 AI」，而是你一个人的助理，每次开口都按你定的性格和风格来。定完之后不用学任何技巧，就像给朋友发消息一样交代第一件小事：「帮我看看这周邮箱里有没有重要的事。」（我自己的助理就叫 Catherine，这份展示就是她做的。）

03

接上 Google 这把钥匙

先设成「只准看、不准动」，用一周放心了再放开。顺手把安全设置做好：发邮件、花钱这类动作，都设成「每次先问我」——闸门在你手里，它才敢放手干活。

04

让它每周替你盯一件事

比如「每周日晚帮我看一次补习班通知」。这种每周都发生的小事最适合它：你只交代一次，它一直记着。
